# SBMP Academic Hub

A responsive academic portal for First-Year Computer Engineering students at
Shri Bhagubhai Mafatlal Polytechnic & College of Engineering (SBMP).

**Live Site:** https://omsherlekar29.github.io/sbmp-academic-hub1/

---

## Features

- Live analog + digital clock
- Timetable with Full / S1 / S2 batch filtering
- 7 subject pages with full syllabus
- Faculty directory (9 members)
- Student directory (63 students, search + filter)
- Notices with academic calendar
- Attendance tracker with PDF import + CSV export
- Task planner (per-subject and all-subject)
- Feedback form
- Dark mode
- Fully responsive (mobile + desktop)

---

## Tech Stack

- HTML5 · CSS3 · JavaScript (ES Modules)
- localStorage for persistence
- PDF.js for attendance PDF parsing
- Deployed on GitHub Pages

---
